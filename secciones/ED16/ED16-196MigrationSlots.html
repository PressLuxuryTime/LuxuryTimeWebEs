196, esos serán los espacios para migración


MsLadyGrim

Faltando menos de una semana para terminar la temporada 4, la migración empezará para la transición a una quinta temporada. Los espacios para inmigrar a cada Estado estarán conformados por cuatro diferentes niveles.


Para el "espacio de invitación de inmigración de élite", contarán con solo 1 espacio; para el nivel avanzado, 5 espacios; para el nivel medio, 20; y para el nivel regular, 170 espacios para inmigración.


No ser parte de ninguna alianza, el sobreviviente debe mantener una "identidad regular" o haber recibido invitación, no ser Presidente en ejercicio durante la migración son algunas de las condiciones para migrar. Para utilizar el espacio de inmigración regular, debe tener Atalaya 30 o inferior.


MeowFIA [XOXO] y THE PATROL 2.0 [PA13], ahora THE ROGUE PATROL [RO13], son las dos alianzas que han inmigrado al Estado 89 para la temporada 4.
